Changelog

Stay up to date with the latest improvements, bug fixes, and enhancements in Facebook Desktop. This page highlights version history and notable changes by release.

Version 1.0.0 — Initial Release

  • 🎉 Launched the first stable version of Facebook Desktop
  • 🖥️ Basic feed viewing and post interaction support
  • 🔐 login and authentication integration
  • 📥 Support for Windows installers and portable builds

This initial release provides a desktop‑optimized interface for Facebook, enabling users to browse their feed and post directly from their computer.

Planned Updates

Future releases are planned to include:

  • 📌 Multi‑column views (similar to web multi‑feed experience)
  • 🖼️ Embedded media preview enhancements
  • 🛠️ Accessibility improvements
  • 🔄 Real‑time update / “live feed” toggle

Check back here for official updates and dates.
