Build from Source (Developers & Contributors)

If you’d like to compile Facebook Desktop yourself (for example, to test a feature or help contribute), you can clone the repo and build locally from source: 

git clone https://github.com/AppsForWindowsDesktop/facebook-desktop.git
cd facebook-desktop
msbuild "Facebook desktop\Facebook desktop.sln" /p:Configuration=Release /p:SelfContained=True /p:PackageAsSingleFile=true /t:Publish /p:PublishDir=Publish
makensis installer_script.nsi

This method gives you the latest development builds which may not be published yet on the official releases page.
